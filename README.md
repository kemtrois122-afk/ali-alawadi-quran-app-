# مشروع أولي لتطبيق «علم ينتفع به – الدكتور علي العوضي»

هذا **مشروع مصدر تجريبي** لتغليف الموقع الحالي على Android وiOS باستخدام Capacitor. **ليس APK أو IPA جاهزًا، ولم يُنشر على أي متجر**.

## Windows / Android
1. ثبّت Node.js LTS وAndroid Studio وJDK المتوافق مع إصدار Capacitor المستخدم.
2. افتح Terminal داخل هذا المجلد، ثم نفّذ `npm install`.
3. نفّذ `npx cap add android` ثم `npx cap open android`.
4. في Android Studio اختبر التطبيق على جهاز فعلي، وراجع الأيقونة، إعدادات الإشعارات، الأذونات، سياسة الخصوصية، وأداء الصوت.
5. أنشئ ملف Android App Bundle **موقّعًا** عبر Build > Generate Signed Bundle / APK. احتفظ بمفتاح التوقيع بسرية.
6. ارفع AAB إلى Google Play Console أولًا على مسار اختبار، ثم استوفِ متطلبات النشر والمراجعة.

## iOS / iPhone
1. تحتاج macOS مع Xcode، سواء على Mac أو خدمة بناء سحابية موثوقة تتيح Xcode والتوقيع.
2. على بيئة macOS نفّذ `npm install` ثم `npx cap add ios` ثم `npx cap open ios`.
3. اضبط Signing & Capabilities باستخدام Apple Developer، واختبر على iPhone وTestFlight قبل إرسال التطبيق إلى App Review.

## تنبيهات مهمة
- هذه النسخة تعرض الموقع المستضاف عبر `server.url`؛ **لا تعمل بالكامل دون إنترنت**. تحويلها إلى تطبيق أوفلاين حقيقي يتطلب تجميع الواجهة والبيانات والأصول محليًا وإعادة تصميم الأجزاء المعتمدة على الخادم.
- الإشعارات في الخلفية والأذان والتلاوات وملفات التنزيل تحتاج اختبارًا وتكاملًا أصليًا؛ لا تُعد مفعّلة لمجرد تغليف الموقع.
- Apple قد ترفض التطبيقات التي تقدم تجربة WebView محدودة لا تختلف بما يكفي عن الموقع؛ ينبغي إضافة قيمة أصلية قبل تقديمها للمراجعة.
- معرف الحزمة `org.alialawadi.quran` **اقتراح مبدئي**، ويجب التحقق من توفره وتثبيته قبل إنشاء التطبيقات على المتاجر.
- راجع الحقوق والتراخيص المتعلقة بالتلاوات والمحتوى والصور، وسياسة الخصوصية، وبيانات التطبيق قبل النشر.
- التطبيق مجاني بلا إعلانات أو اشتراكات أو مشتريات داخل التطبيق.
